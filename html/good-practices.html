About This Page

This page demonstrates simple good practices when writing HTML. Following these practices keeps your code accessible, maintainable, and SEO-friendly.

Key Practices

  1. Always declare <!DOCTYPE html> at the top.
  2. Set the lang attribute on <html>.
  3. Include a <meta charset="UTF-8"> tag.
  4. Add a meaningful <title>.
  5. Use semantic elements such as <header>, <nav>, <main>, <section>, <article>, and <footer>.
  6. Keep heading levels in logical order (h1 → h2 → h3…).
  7. Always add alt text to images.
  8. Associate every form field with a <label>.
  9. Use <button> for interactive actions, not plain <div>.
  10. Write descriptive link text instead of "click here".
